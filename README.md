Weapon is my first chess engine, coded in C++

This simple and lightweight project uses a modular architecture that separates board representation, move generation, position evaluation, 
search, and UCI communication. Its search algorithm is based on Minimax with Alpha-Beta pruning, with additional optimizations 
planned to improve search efficiency.

Featuring:

Legal move generation and chess rule handling.

Position evaluation based on material and positional factors.

Minimax search with Alpha-Beta pruning.

Iterative deepening, transposition tables, and quiescence search.

UCI protocol support for compatibility with chess GUIs.

Cross-platform compilation on Windows and Linux.

Automated testing to validate move generation and search correctness.

The project prioritizes a simple, maintainable implementation that can be progressively improved with more advanced search techniques and evaluation methods.
